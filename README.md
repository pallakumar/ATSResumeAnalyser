##  Overview

ATS Resume Analyzer is an iOS application that analyzes resumes, evaluates ATS compatibility, and provides actionable recommendations to improve resume quality and increase visibility to recruiters.

The application extracts resume content from PDF files, performs keyword analysis, calculates an ATS score, and generates suggestions for optimization.

## Features

- Upload PDF Resume
- Resume Content Extraction
- ATS Score Calculation
- Keyword Analysis
- Resume Improvement Suggestions
- Modern SwiftUI Interface
- MVVM Architecture
- Responsive User Experience

## Tech Stack

- Swift
- SwiftUI
- MVVM Architecture
- PDFKit
- REST APIs
- AI Integration

## Getting Started

### Prerequisites

- Xcode 16+
- iOS 18+
- macOS Sequoia or later

### Installation

Clone the repository:

git clone https://github.com/pallakumar/ATSResumeAnalyser.git

Open the project in Xcode:

cd ATSResumeAnalyser
open ATSResumeAnalyser.xcodeproj

Build and run on Simulator or Device.
